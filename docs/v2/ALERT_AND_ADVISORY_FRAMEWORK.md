## 1. Advisory Tier Definitions

GeoSlide-JK 2.0 establishes a 4-tier standardized advisory framework aligned with national disaster management standards:

```
🟩 GREEN (Normal Baseline)   ➔ Static Susceptibility < 0.35 | Anomaly Ratio < 1.0x
🟨 YELLOW (Watch)            ➔ Static Susceptibility 0.35 - 0.55 OR Anomaly Ratio 1.0x - 1.5x
🟧 ORANGE (High Risk)        ➔ Static Susceptibility 0.55 - 0.75 AND Anomaly Ratio 1.5x - 2.0x
🟥 RED (Critical Risk)       ➔ Static Susceptibility > 0.75 AND Anomaly Ratio > 2.0x
```

## 3. Mandatory Research Disclaimer Text

Every advisory card, API payload, and export document MUST retain the non-negotiable legal disclaimer:

> **"⚠️ RESEARCH ADVISORY NOTICE:**  
> *GeoSlide-JK advisories are generated by an experimental research decision-support prototype using geospatial machine learning and rainfall proxy scenarios. They DO NOT constitute official government warnings, mandatory evacuation orders, or legal road closure declarations. Official emergency notices remain under the exclusive jurisdiction of the J&K State Disaster Management Authority (SDMA) and J&K Traffic Police."*

---

## 4. Official Approval Workflow for Live Alerts

To prevent false alarms and unverified public panic, public push notifications (e.g. SMS / WhatsApp alerts) require human-in-the-loop official verification:

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│ 1. SYSTEM SCAN  │ ──► │ 2. DRAFT ALERT  │ ──► │ 3. OFFICIAL     │ ──► │ 4. PUBLIC PUSH  │
│ Automated IPS   │     │ Created in DDMA │     │ HUMAN APPROVAL  │     │ Notification    │
│ Threshold Event │     │ Officer Queue   │     │ (SDMA Officer)  │     │ Dispatch        │
└─────────────────┘     └─────────────────┘     └─────────────────┘     └─────────────────┘
```

Unauthenticated public users can view passive web advisories, but automated broadcast notifications require Step 3 approval by an authorized official.
